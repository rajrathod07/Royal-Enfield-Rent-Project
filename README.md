# My Website Project


## How to Run the Project

1. Make sure XAMPP is installed on your system.
2. Copy the project folder to the XAMPP `htdocs` directory.
   - Example path: `C:\xampp\htdocs\`  
3. Start Apache from the XAMPP Control Panel.
4. Open your browser and type the project URL: 
http://localhost/A-82-Rathod%20Raj%20Dineshbhai/Project/

5. website should now load in the browser.

## Notes
- If you change the folder name, update the URL accordingly.
